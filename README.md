
# NOEMI — адаптивная вёрстка сайта

**NOEMI** — адаптивная страница блога о творчестве, спорте и образе жизни, свёрстанная на HTML и CSS по предоставленным дизайн-макетам для десктопа, планшета и смартфона.

Вёрстка адаптируется к ширине экрана и ориентации устройства. Для построения сеток используются Flexbox и CSS-медиазапросы.

Проект выполнен в рамках итоговой работы по модулю **«Адаптивная и мобильная вёрстка»** Нетологии.

## О проекте

NOEMI — учебный проект по адаптивной и мобильной вёрстке, выполненный на основе [дизайн-макетов Нетологии](https://github.com/netology-code/mq-diploma).

Основная задача заключалась в создании HTML- и CSS-вёрстки страницы по предоставленным PSD-макетам для трёх типов экранов:

- Десктоп — от 1200 px.
- Планшет — от 641 до 1200 px.
- Смартфон — до 640 px.

Помимо основных макетов требовалось обеспечить адаптацию элементов к промежуточным размерам экранов и изменение расположения карточек при повороте устройства.

В ходе работы реализовал разметку страницы, адаптивные сетки, оформление элементов интерфейса и отображение изображений в зависимости от ширины экрана.

Проект представляет собой статическую страницу без серверной части и JavaScript-логики.

## Функциональность и структура страницы

### Шапка сайта

В верхней части страницы расположены логотип, навигационное меню и основной заголовок.

На десктопных экранах отображается горизонтальная навигация.

На планшетах и смартфонах вместо неё отображается иконка бургер-меню.

В рамках проекта реализовано отображение элементов навигации в зависимости от ширины экрана. Открытие и закрытие мобильного меню по нажатию не предусмотрено.

### Блок «Сейчас в тренде»

Раздел содержит четыре карточки публикаций с изображениями, категориями и заголовками.

Количество колонок зависит от ширины экрана и ориентации устройства.

| Тип экрана | Портретная ориентация | Альбомная ориентация |
| --- | --- | --- |
| Мобильный, до 640 px | 1 колонка | 2 колонки |
| Планшет, 641–1200 px | 2 колонки | 4 колонки |
| Десктоп, от 1201 px | 4 колонки | 4 колонки |

При изменении ширины экрана карточки перестраиваются, а изображения заполняют доступную область.

### Основной контент

Основная часть страницы содержит список публикаций и боковую панель.

Карточки публикаций включают:

- Изображение.
- Категории и заголовок.
- Дату публикации и автора.
- Текстовое описание.

На десктопных экранах изображение и текст публикации располагаются рядом. На мобильных экранах используется вертикальное расположение элементов.

### Боковая панель

В боковой панели размещены:

- Список новых публикаций.
- Форма поиска.
- Форма подписки на рассылку.
- Список тегов.
- Список тематических категорий.

На планшетных и десктопных экранах боковая панель располагается рядом с основным списком публикаций.

На мобильных экранах блоки располагаются последовательно друг под другом.

### Карточки товаров

Раздел «Наши изделия» содержит три карточки товаров.

В каждой карточке предусмотрены изображение, название, описание, стоимость и кнопка перехода в магазин.

Количество колонок изменяется в зависимости от ширины экрана:

- Мобильный экран — 1 колонка.
- Планшет — 2 колонки.
- Десктоп — 3 колонки.

Для изображений товаров используется элемент `<picture>`, позволяющий выбирать графические ресурсы для разных размеров экрана.

### Форма обратной связи

Реализована HTML- и CSS-вёрстка формы обратной связи.

Форма содержит:

- Выпадающий список частоты посещения сайта.
- Переключатели подписки на рассылку.
- Текстовое поле для обратной связи.
- Кнопку отправки.

В проекте форма находится в скрытом состоянии.

Открытие, закрытие и отправка данных формы не реализованы, поскольку в рамках учебного задания требовалась только её вёрстка.

## Технические решения

### Адаптация под разные экраны

В проекте использован подход Mobile First: базовые стили размещены в `mobile.css`, а для планшетных и десктопных экранов подключаются дополнительные файлы со стилями.

```html
<link rel="stylesheet" href="css/mobile.css" />

<link
  rel="stylesheet"
  href="css/tablet.css"
  media="(min-width: 641px)"
/>

<link
  rel="stylesheet"
  href="css/desktop.css"
  media="(min-width: 1201px)"
/>
```

Такое разделение позволяет задавать базовое оформление для мобильных экранов и переопределять необходимые свойства при увеличении ширины экрана.

Основные точки переключения в текущей реализации — 641 и 1201 px.

### Реализация сеток с помощью Flexbox

Для построения основных сеток используется Flexbox.

В частности, с помощью `display: flex`, `flex-direction`, `flex-wrap` и `gap` реализовано расположение карточек публикаций, трендов и товаров.

При изменении ширины экрана соответствующие медиазапросы переопределяют направление и размеры элементов.

Это позволяет изменять количество колонок без использования JavaScript.

### Адаптация к ориентации устройства

Для изменения расположения карточек трендов используются CSS-медиазапросы с условием `orientation: landscape`.

На мобильных экранах при переходе в альбомную ориентацию карточки располагаются в две колонки.

На планшетных экранах в альбомной ориентации количество колонок увеличивается до четырёх.

### Адаптивные изображения

Для изображений в карточках товаров используется HTML-элемент `<picture>`.

Он позволяет подключать разные версии изображений в зависимости от ширины экрана.

Пример из проекта:

```html
<picture>
  <source
    srcset="images/shop-item-desk1.jpg"
    media="(min-width: 1201px)"
  />

  <source
    srcset="images/shop-item-tablet1.jpg"
    media="(min-width: 768px) and (max-width: 1200px)"
  />

  <img
    class="product-card__image"
    src="images/shop-item-mobile1.jpg"
    alt=""
  />
</picture>
```

Для оформления изображений также используются свойства `object-fit` и `object-position`.

### Семантическая разметка

При создании структуры страницы использованы семантические элементы HTML5:

- `<header>` — шапка страницы и заголовки публикаций.
- `<nav>` — навигационное меню.
- `<main>` — основное содержимое.
- `<section>` — тематические разделы.
- `<article>` — отдельные публикации и карточки.
- `<aside>` — боковая панель.
- `<footer>` — нижняя часть страницы.
- `<time>` — даты публикаций.

Для визуального скрытия вспомогательных текстовых описаний используется класс `visually-hidden`.

### Организация CSS

Стили разделены на файлы в зависимости от типа экрана:

| Файл | Назначение |
| --- | --- |
| `mobile.css` | Базовые стили страницы и оформление мобильной версии |
| `tablet.css` | Адаптация элементов для планшетных экранов |
| `desktop.css` | Оформление десктопной версии |
| `normalize.css` | Нормализация стандартных браузерных стилей |

Для именования CSS-классов используются названия блоков, элементов и модификаторов, например `post`, `post__title` и `button--search`.

## Технические задачи и решения

### 1. Адаптация сетки к разным размерам экрана

**Задача**

Сверстать страницу по трём предоставленным макетам и обеспечить адаптацию элементов к промежуточным размерам экранов.

При уменьшении ширины экрана необходимо изменять расположение публикаций, боковой панели и карточек товаров.

**Решение**

Использовал Flexbox для построения сеток и CSS-медиазапросы для изменения расположения элементов.

Базовые стили разместил в `mobile.css`, а оформление планшетной и десктопной версий вынес в отдельные файлы.

Для основного контейнера предусмотрел ограничение максимальной ширины и автоматическое центрирование.

**Результат**

Реализована адаптивная структура страницы с разным расположением основного контента, боковой панели и карточек для мобильных, планшетных и десктопных экранов.

### 2. Изменение расположения карточек при повороте устройства

**Задача**

Обеспечить разное расположение карточек раздела «Сейчас в тренде» для портретной и альбомной ориентации экрана.

**Решение**

Реализовал переключение количества колонок с помощью Flexbox и CSS-медиазапросов с условием `orientation: landscape`.

На мобильных экранах при повороте устройства карточки перестраиваются из одной колонки в две, а на планшетных — из двух в четыре.

**Результат**

Количество колонок в разделе «Сейчас в тренде» изменяется в зависимости от ширины экрана и ориентации устройства без использования JavaScript.

### 3. Отображение изображений на разных экранах

**Задача**

Использовать подходящие изображения товаров для мобильной, планшетной и десктопной версий страницы.

**Решение**

Применил HTML-элемент `<picture>` с несколькими элементами `<source>` и условиями `media`.

Для оформления изображений использовал свойства CSS, позволяющие управлять их размерами и расположением внутри карточек.

**Результат**

Браузер выбирает соответствующую версию изображения товара в зависимости от заданных условий ширины экрана.

## Результат

В рамках учебного проекта реализована адаптивная HTML- и CSS-вёрстка страницы NOEMI по предоставленным дизайн-макетам.

В ходе работы применил семантическую HTML-разметку, адаптивную вёрстку, CSS-псевдоэлементы, работу со шрифтами, SVG и адаптивными изображениями.

Проект опубликован на GitHub Pages и доступен для просмотра в браузере.
