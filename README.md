
# NOEMI — адаптивная вёрстка сайта

NOEMI — учебный проект по HTML- и CSS-вёрстке адаптивной страницы блога о творчестве, спорте и образе жизни.

Страница свёрстана по предоставленным дизайн-макетам для десктопа, планшета и смартфона с учётом изменения ширины экрана и ориентации устройства.

Проект выполнен в рамках итоговой работы по модулю «Адаптивная и мобильная вёрстка» Нетологии.

## Основные особенности

- Адаптивная вёрстка для десктопных, планшетных и мобильных экранов.
- Семантическая HTML-разметка.
- Адаптивные сетки публикаций, трендов и товаров.
- Изменение расположения элементов при повороте устройства.
- Отображение изображений с учётом ширины экрана.
- Формы поиска, подписки и обратной связи.
- Адаптация навигации для мобильных устройств.
- Оформление элементов интерфейса с помощью CSS.

## Технологии

**Разметка:** HTML5, семантические элементы, формы, picture.

**Стилизация:** CSS3, Flexbox, Media Queries, псевдоэлементы, псевдоклассы.

**Графика:** SVG, адаптивные изображения, локальные веб-шрифты.

**Публикация:** GitHub Pages.

В проекте не использовались JavaScript-фреймворки, CSS-препроцессоры или сборщики.

## Техническая реализация

### Адаптивная вёрстка

При разработке использовал подход Mobile First.

Базовые стили определены для мобильной версии страницы, а для планшетных и десктопных экранов подключаются дополнительные CSS-файлы.

Основные точки переключения:

| Устройство | Ширина экрана |
| --- | --- |
| Смартфон | До 640 px |
| Планшет | От 641 до 1200 px |
| Десктоп | От 1201 px |

**Основные файлы:**

- [mobile.css](css/mobile.css) — базовые стили и мобильная версия.
- [tablet.css](css/tablet.css) — стили для планшетных экранов.
- [desktop.css](css/desktop.css) — стили для десктопных экранов.

### Построение адаптивных сеток

Для расположения основных блоков использовал Flexbox.

С помощью `display: flex`, `flex-direction`, `flex-wrap` и других CSS-свойств реализовал сетки публикаций, трендов и товаров.

Медиазапросы изменяют направление и размеры элементов в зависимости от ширины экрана.

Это позволяет адаптировать расположение контента без использования JavaScript.

### Адаптация к ориентации устройства

Для блока «Сейчас в тренде» реализовал изменение количества колонок с помощью CSS-медиазапросов.

На мобильных устройствах при переходе в альбомную ориентацию карточки располагаются в две колонки.

На планшетных экранах в альбомной ориентации количество колонок увеличивается до четырёх.

### Адаптивные изображения

Для отображения изображений в карточках товаров использовал HTML-элемент `picture`.

Это позволяет выбирать подходящий графический ресурс в зависимости от условий отображения.

Дополнительно настроил размеры изображений и их размещение внутри контейнеров с сохранением пропорций.

### Семантическая разметка

При создании HTML-структуры использовал семантические элементы для разделения основных областей страницы.

Реализовал разметку навигации, публикаций, боковой панели и форм.

Для контентных изображений добавил альтернативные текстовые описания.

## Установка и запуск

Проект представляет собой статическую HTML-страницу и не требует установки зависимостей.

**1. Клонируйте репозиторий**

```bash
git clone https://github.com/potykalov/mq-diploma.git
cd mq-diploma
```

**2. Откройте страницу**

Откройте файл `index.html` в браузере.
